\# Industrial Equipment Monitoring Dashboard



Industrial-style monitoring dashboard built with a \*\*single HTML file\*\*.



This project simulates a factory monitoring interface including clock gauges, alarm systems, equipment KPIs and trend charts.



\## Features



\- Industrial analog clock

\- Digital time display

\- Temperature / Pressure / RPM gauges

\- Alarm system with warning lights

\- Buzzer alarm simulation

\- ACK / RESET alarm control

\- AUTO / MANUAL / MAINT operation mode

\- Equipment KPI monitoring

\- Trend charts

\- Event log \& Alarm log

\- Runs with a single HTML file



\## Usage



Download the repository and open:



index.html



in any browser (Chrome / Edge recommended).



No installation required.
